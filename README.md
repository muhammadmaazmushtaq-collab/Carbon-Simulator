# Carbon Simulator 🌍

An Object-Oriented Programming (OOP) based application developed in **C#** to simulate and track carbon footprints. This academic project focuses on building a modular, scalable, and structured architecture using core OOP principles.

## 🚀 Features & OOP Concepts Implemented
* **Classes & Objects:** Structured the simulation entities into distinct, manageable classes.
* **Encapsulation:** Protected sensitive data related to carbon metrics using access modifiers and properties.
* **Inheritance & Polymorphism:** Created flexible and reusable code hierarchies to handle different types of carbon emission sources dynamically.
* **Detailed Documentation:** Includes a comprehensive Project Submission Report outlining the system architecture and logic.

## 💻 Tech Stack
* **Programming Language:** C# 
* **Core Concepts:** Object-Oriented Programming, System Design, Modular Architecture.
